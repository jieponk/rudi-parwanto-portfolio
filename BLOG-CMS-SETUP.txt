BLOG + CMS SETUP — RUDI PARWANTO / CLOUDFLARE

Build command Cloudflare Workers Builds:
  npm run build
Deploy command:
  npx wrangler deploy

Decap CMS memakai GitHub OAuth proxy yang berada di worker.js.
Buat GitHub OAuth App:
- Homepage URL: https://masrudi.site
- Authorization callback URL: https://masrudi.site/api/callback

Di Cloudflare Dashboard > Workers & Pages > rudi-parwanto-portfolio > Settings > Variables and Secrets, tambahkan sebagai Secret:
- GITHUB_OAUTH_ID = Client ID dari GitHub OAuth App
- GITHUB_OAUTH_SECRET = Client Secret dari GitHub OAuth App

Tambahkan juga Secret untuk halaman /master/:
- MASTER_USERNAME
- MASTER_PASSWORD
- MASTER_SECRET (string acak panjang minimal 32 karakter)

Setelah deploy dan secrets tersimpan, buka https://masrudi.site/admin/ lalu login dengan GitHub.
Decap CMS akan commit konten ke repository GitHub. Cloudflare akan build ulang blog, feed.xml, dan sitemap.xml setelah commit.

URL utama:
- /admin/       CMS blog
- /master/      kalkulator marketplace
- /blog/        daftar artikel
- /feed.xml     RSS
- /sitemap.xml  sitemap mesin pencari
- /robots.txt   aturan crawler

Jangan masukkan Client Secret, MASTER_PASSWORD, atau MASTER_SECRET ke repository.
