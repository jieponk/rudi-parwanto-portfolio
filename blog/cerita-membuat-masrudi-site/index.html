Cerita di Balik masrudi.site: Dari CV Online sampai Editor Bergaya VS Code

Perjalanan membangun portofolio pribadi: pindah ke Cloudflare, domain sempat di-suspend, lalu dirombak total jadi editor VS Code bergaya macOS lengkap dengan blog.

Setiap orang yang kerja di e-commerce pasti pernah ditanya, "Ada portofolio?" Biasanya jawabannya kirim CV PDF, lalu selesai. Saya ingin sesuatu yang lebih dari itu: satu alamat yang bisa saya bagikan ke siapa saja, berisi pengalaman, proyek, dan catatan kerja saya.

Dari situ lahir masrudi.site.

Awalnya: CV yang dibuat jadi website

Versi pertama sederhana sekali. Isinya pengalaman kerja, skill, pendidikan, dan kontak, dengan tampilan "CV Studio" yang meniru jendela editor kode. Saya memilih tema editor karena dua alasan:

  • pekerjaan saya sekarang makin banyak bersinggungan dengan sistem dan automasi, bukan cuma operasional toko;
  • tampilan seperti editor terasa lebih "saya" dibanding template portofolio biasa.

Setelah itu menyusul halaman Links untuk bio media sosial dan Blog untuk menulis catatan.

Tips

Kalau kamu baru mau bikin portofolio, mulai saja dari versi paling sederhana. Website yang online lebih berguna daripada desain sempurna yang tidak pernah selesai.

Pindah rumah ke Cloudflare

Awalnya website ini di-hosting di Netlify. Seiring bertambahnya fitur, termasuk kalkulator marketplace yang butuh login dan CMS blog yang butuh login GitHub, saya memindahkannya ke Cloudflare Workers.

Momen paling bikin panik: domain di-suspend

Belum sebulan domain dipakai, website tiba-tiba tidak bisa diakses. Setelah dicek di lookup ICANN, statusnya serverHold: domain ditahan langsung oleh registry, bukan oleh tempat saya membeli domain.

Penyebabnya ternyata laporan phishing dari Spamhaus. Padahal isinya cuma portofolio. Dugaan terkuat saya: domain baru dengan ekstensi murah, ditambah ada halaman berisi form login (kalkulator internal), cukup untuk memicu sistem deteksi otomatis.

Yang saya lakukan:

  1. Cek status domain di lookup ICANN untuk memastikan jenis suspend-nya.
  2. Hubungi support registrar untuk tahu alasan pastinya.
  3. Pastikan domain sudah bersih di Spamhaus.
  4. Ajukan form unsuspension ke registry dengan bukti: screenshot website, bukti kepemilikan domain, dan profil profesional.
Berhasil

Tidak lama setelah form dikirim, status serverHold dicabut dan website kembali online.

Perhatian

Pelajaran penting: di domain baru, halaman login yang bisa diakses publik gampang dicurigai sebagai phishing. Kalau punya halaman internal, lindungi dengan lapisan tambahan atau pisahkan ke subdomain.

Dirombak total: VS Code × macOS

Setelah domain aman, saya merasa tampilannya mulai ketinggalan zaman. Jadi saya rombak semuanya mengikuti gaya VS Code di macOS terbaru:

BagianSekarang
Menu barEfek kaca (glass) ala macOS, lengkap dengan jam
NavigasiActivity bar, explorer, tab file, breadcrumb, status bar
KontenPanel preview di bawah potongan kode about.js, projects.js, dll.
TemaGelap & terang, tersimpan di semua halaman
BahasaEnglish & Indonesia
EkstraPencarian ⌘K, panel terminal, musik latar

Blog, halaman Links, kalkulator, sampai halaman 404 ikut memakai bingkai yang sama, jadi semuanya terasa satu aplikasi.

Yang sering terlupa: SEO dan detail kecil

Website yang bagus belum tentu ketemu di Google. Beberapa hal yang saya perbaiki:

  • Isi halaman utama ditulis langsung di HTML, tidak menunggu JavaScript, supaya mudah dibaca mesin pencari.
  • Data terstruktur (schema) untuk profil, supaya Google paham ini profil profesional.
  • Gambar share 1200×630: dulu preview link di WhatsApp cuma foto kecil.
  • Favicon baru dalam beberapa ukuran, termasuk ikon untuk layar utama HP.
Catatan

Detail kecil seperti preview link sering jadi kesan pertama, karena orang biasanya melihat link-mu di chat sebelum membuka websitenya.

Pelajaran yang saya bawa pulang

  • Mulai sederhana, rapikan belakangan. Versi pertama tidak perlu sempurna.
  • Otomatiskan yang berulang. Build dan deploy otomatis menghemat banyak waktu.
  • Pahami infrastrukturnya. Kasus suspend mengajarkan saya cara kerja domain, registry, dan reputasi.
  • Konsisten itu mahal tapi worth it. Satu bahasa desain di semua halaman membuat website terasa profesional.

Website ini akan terus berkembang. Kalau kamu sedang membangun portofolio sendiri dan bingung mulai dari mana, kolom komentar di bawah terbuka untuk ngobrol. 👋
