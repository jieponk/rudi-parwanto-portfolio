Test Postingan Pertama Blog

25 September 2026 · Rudi Parwanto
# Test

Halo, ini postingan pertama!

Artikel ini dibuat sebagai pengujian pertama sistem blog di website Rudi Parwanto.

Tujuannya sederhana: memastikan proses publikasi artikel dapat berjalan tanpa perlu mengedit HTML dan melakukan deploy website secara manual setiap kali membuat postingan baru.

Apa yang sedang diuji?

Pada postingan ini, saya ingin memastikan beberapa bagian utama sudah berjalan dengan benar:

  • Pembuatan artikel melalui CMS
  • Upload gambar thumbnail
  • Penyimpanan artikel ke GitHub
  • Auto deploy melalui Netlify
  • Pembuatan halaman artikel
  • Tampilan artikel di halaman Blog
  • Sitemap untuk mesin pencari
  • RSS feed

Kenapa Sistem Ini Dibuat?

Website ini awalnya merupakan portfolio pribadi. Dengan adanya sistem blog, website juga dapat digunakan untuk berbagi pengalaman dan pengetahuan yang saya dapatkan selama bekerja di bidang e-commerce.

Ke depannya, topik yang dibahas akan lebih berfokus pada e-commerce, marketplace, optimasi listing produk, workflow, kamera, dan berbagai hal yang berkaitan dengan pekerjaan maupun project yang saya kerjakan.

Test Publish

Jika kamu sedang membaca halaman ini dari website, berarti proses CMS → GitHub → Netlify → Blog sudah berhasil berjalan.

Selanjutnya, artikel test ini dapat diganti dengan konten yang sebenarnya.
